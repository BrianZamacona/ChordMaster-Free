# 🎸 Learn & Strum

[![CI](https://github.com/BrianZamacona/ChordMaster-Free/actions/workflows/ci.yml/badge.svg)](https://github.com/BrianZamacona/ChordMaster-Free/actions/workflows/ci.yml)
[![Flutter](https://img.shields.io/badge/Flutter-3.47-blue.svg)](https://flutter.dev)

App gratuita para aprender guitarra que explica **por qué** suena cada acorde, escala y
progresión. Sin anuncios, sin cuentas y sin conexión: todo funciona en el teléfono.
Disponible en español e inglés, con tema claro y oscuro.

> **English:** Learn & Strum is a free, offline guitar-learning app (Spanish and English)
> that explains the theory behind every chord, scale and progression. Chord and scale data
> are generated by rules and audited note by note; all sound is synthesized on the device.

---

## Qué tiene

La app se organiza en cinco pestañas.

| Pestaña | Módulo | Qué hace |
|---|---|---|
| **Inicio** | Inicio | Reto del día, racha de días seguidos y acceso rápido a los módulos. |
| **Aprender** | Acordes | 288 acordes (24 tipos × 12 tonalidades) y 1816 digitaciones: principal, CAGED, voicings, tríadas en los cuatro grupos de cuerdas, inversiones, Drop 2 y Drop 3, power chords (R-5-R y 5-R-5) y formas para principiantes. Elegir cualquier nota del bajo (acordes slash), escuchar cada acorde y comparar hasta tres digitaciones. |
| | Escalas | 12 escalas y los 7 modos, en cualquier tónica y en cuatro sistemas (CAGED, 3 y 4 notas por cuerda, cajas pentatónicas). Tarjetas "¿Por qué?": pasos T/S, nota característica, acordes que la armonizan, octavas de la tónica e ideas para improvisar. |
| | Double stops | Pares de notas diatónicos (3ª, 6ª…) por grupo de cuerdas. |
| | Progresiones | 9 progresiones clásicas o "Mi progresión" por grados. La app elige las digitaciones con menos saltos (formas abiertas primero), explica la función de cada acorde y las cadencias, deja cambiar cualquier digitación desde un glosario y reproduce la progresión. |
| **Practicar** | Oído | Intervalos melódicos o armónicos sobre una nota grave al azar; la respuesta se ve solo al contestar. |
| | Ritmo | Tocar a tiempo con el pulso (±75 ms); récord desde 16 toques. |
| | Canciones | Canciones conocidas con sus acordes (sin letras), ritmo y tempo; cada acorde abre su ficha. |
| **Afinar** | Afinador | Afinador cromático con el micrófono y La de referencia ajustable. |
| | Metrónomo | Metrónomo con acento y tap tempo. |
| **Progreso** | Logros, Salud y Ajustes | Logros alcanzables, sesión de práctica con avisos de pausa y calentamiento, idioma y tema. |

## Cómo funciona

### Datos musicales generados por reglas
Ninguna digitación ni posición de escala se escribe a mano.

- **Acordes:** `assets/data/chords.json`, generado por `tool/regenerate_chord_data.py`.
- **Escalas:** `assets/data/scales_master.json`, generado por `tool/regenerate_scales_master.py`.

Cada archivo tiene su auditoría (`tool/audit_*.py`) y sus tests, que exigen que **toda nota
tocada pertenezca al acorde o a la escala**, con tolerancia cero. Los generadores son
idempotentes: correrlos dos veces no cambia nada.

### Teoría con explicación
Las tarjetas "¿Por qué?" no son texto fijo. Las calculan reglas en `lib/domain/theory/`:
- `harmony.dart`: función de cada grado, cadencias y notas comunes.
- `scale_insights.dart`: pasos, comparación con mayor y menor, acordes diatónicos e ideas para improvisar.
- `octaves.dart`: formas de octava deducidas de la afinación.
- `intervals.dart`: nombres de intervalos.

Cada afirmación tiene un test que la verifica.

### Progresiones
Para cada grado se toman las digitaciones de `chords.json` que son tocables y, si el acorde
tiene formas abiertas, solo esas. Después, programación dinámica busca el camino de menor
costo: ergonomía, salto de la nota más aguda, cambio de traste y notas que se mantienen.
El modo Principiante penaliza las cejillas. Lo que el usuario elige en el glosario
reemplaza solo ese acorde.

### Acordes slash
Se generan al momento (`lib/domain/voicing/slash_chords.dart`): el bajo elegido va en la
6ª, 5ª o 4ª cuerda sobre las digitaciones del acorde. Arriba se conservan la raíz y la 3ª,
el bajo es la nota más grave y la forma tiene que caber en cuatro dedos.

### Sonido y afinador
- **Sin archivos de audio.** Todo el sonido se sintetiza en Dart (`lib/domain/audio/pluck_synth.dart`):
  - cuerda pulsada (Karplus-Strong) afinada con menos de 1 cent de error;
  - clic de metrónomo.

  Cada sonido se escribe una vez como WAV temporal y se reproduce con `just_audio`.
- **Afinador:** lee el micrófono en PCM a 44.1 kHz, lo baja a 22.05 kHz y detecta la nota
  con el algoritmo YIN (`lib/domain/audio/pitch_detection.dart`). La mediana de 5 lecturas
  estabiliza la aguja.

### Privacidad
- La app no pide permiso de internet ni lleva analítica o anuncios.
- El progreso y los ajustes se guardan solo en el teléfono, en Hive cifrado con AES; la
  llave queda en el almacén seguro del sistema.
- El micrófono se analiza al momento y no se graba.

Ver la [política de privacidad](docs/privacy-policy.md).

### Interfaz
- Paleta Palisandro (`lib/ui/palette.dart`): el color codifica intervalos y siempre va con
  etiqueta o forma (la raíz es un cuadrado).
- Todos los textos pasan por `tr(es:, en:)`; la app arranca en inglés si el teléfono está
  en inglés y en español en cualquier otro caso.
- Los diagramas del diapasón salen de una sola función de coordenadas y un solo `CustomPainter`.

## Arquitectura

```
lib/
├── domain/        Dart puro, con tests: teoría (armonía, escalas, octavas, double stops),
│                  voicings (ergonomía, conducción de voces, cejillas, slash),
│                  progresiones, sistemas de digitación y audio (síntesis y afinación)
├── data/          Modelos y repositorio de escalas (resuelve posiciones por tónica)
├── models/        Acorde, canción, intervalo…
├── features/      Una carpeta por módulo (pantalla + view-model con Riverpod)
├── ui/            Navegación (5 pestañas), tema, paleta, pantallas de escalas
├── core/          Textos bilingües, constantes, widgets compartidos
└── services/      Audio, afinación, almacenamiento (Hive), notificaciones, logros
assets/data/       chords.json y scales_master.json (generados)
tool/              Generadores, auditorías y el generador del ícono
store/             Ficha de Google Play e ícono de 512 px
docs/              Política de privacidad
```

Estado con **Riverpod**, navegación con **go_router** (un `StatefulShellRoute` con cinco
pestañas) y persistencia con **Hive**. Las convenciones completas y el flujo de trabajo
están en [`CLAUDE.md`](CLAUDE.md).

| Paquete | Versión | Uso |
|---|---|---|
| Flutter / Dart | 3.47 / 3.13 | UI |
| flutter_riverpod | 3.3.2 | Estado |
| go_router | 17.3.0 | Navegación |
| hive · flutter_secure_storage | 2.2.3 · 10.3.1 | Datos locales cifrados |
| just_audio · path_provider | 0.10.6 · 2.1.5 | Reproducir el sonido sintetizado |
| record · permission_handler | 7.1.1 · 12.0.3 | Micrófono del afinador |
| flutter_local_notifications | 22.0.1 | Avisos de pausa |
| google_fonts | 8.1.0 | Fuentes empaquetadas (sin descarga) |
| url_launcher | 6.3.2 | Enlace de donación |

## Empezar

```bash
git clone https://github.com/BrianZamacona/ChordMaster-Free.git
cd ChordMaster-Free
flutter pub get
flutter run
```

Requisitos: Flutter 3.47 o superior (Dart 3.13) y JDK 21 para compilar en Android.

## Tests y auditorías

```bash
flutter analyze
flutter test

# Datos musicales: deben dar 0 defectos
python tool/audit_chord_music.py assets/data/chords.json
python tool/audit_scales_master.py

# Ícono de la app (Android, iOS y tienda), generado desde código
flutter test tool/app_icon/render_app_icon_test.dart

# Límites de texto de la ficha de Google Play
python store/check_listing.py
```
